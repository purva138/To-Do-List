# To-Do List Web Application

A simple task management web application built using Flask, SQLite, HTML, and CSS.

## Features

- Add new tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Undo completed tasks
- Set task priority
- Add due dates
- Search tasks
- Filter tasks
- Sort tasks
- Track task statistics
- Detect overdue tasks
- Store tasks permanently using SQLite

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
